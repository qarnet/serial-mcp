* BACKLOG [#1] PB-009 External decoder/plugin API
  :PROPERTIES:
  :ID:         PB-009
  :TYPE:       feature
  :SIZE:       L
  :AREA:       framing
  :DEPENDS_ON: PB-005

** Problem

In-process framing/parsers cannot cover every proprietary protocol.

** Desired outcome

Pluggable frame decoders/parsers for protocols the built-in modes do not
cover.

** Scope

- A plugin mechanism for frame decoders/parsers.

** Non-goals

- Shell-out execution of arbitrary local binaries without a security
  design.

** Acceptance criteria

- [ ] A third-party decoder can be registered and used through the
      standard read pipeline.
- [ ] Declarative checksums (PB-005) remain the lighter alternative for
      checksum-only needs.

** Technical context

Ship PB-005 first; it covers much of the demand.

** Open questions

Plugin ABI/registration mechanism needs a design before READY.
